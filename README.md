# График смен

React, TypeScript, Hono, Node.js и PostgreSQL. Интерфейс по макету тестового задания Руссмаркет.

## Запуск

Нужны Node.js 22.12+ и Docker либо отдельная PostgreSQL.

```sh
cp .env.example .env
npm ci
docker compose up -d --wait
npm run db:migrate
npm run dev
```

Приложение: http://127.0.0.1:5173. Для своей базы измените `DATABASE_URL` в `.env`.

```sh
npm test
npm run build
npm start
```

Последняя команда раздаёт собранный frontend и API на порту 3001. Тесты API используют базу из `.env`, создают отдельные расписания и удаляют их после проверки.

## Структура

- `src/app` — маршруты, общий layout и провайдеры.
- `src/pages` — главная, список графиков и редактор.
- `src/features/schedule/model` — операции над сменами, выделение, черновик и история изменений. TanStack Query управляет серверными данными, reducer — локальным редактированием.
- `src/features/schedule/ui` — таблица, ячейки, шаблоны, форма своей смены и меню.
- `server/schedule` — HTTP-маршруты, проверка входных данных и PostgreSQL-репозиторий.
- `server/middleware` — сессия и проверка источника запросов.
- `shared` — общие типы и календарные вычисления.

## Работа с графиком

Главная → Графики смен → График. Несохранённые изменения сохраняются при переходах между страницами приложения.

Обычные клики включают и выключают выделение ячеек, Shift + клик выделяет диапазон. Клик по дате выбирает всех найденных сотрудников. Escape закрывает меню без сброса выделения. Своя смена применяется ко всему выделению; время можно изменить и применить повторно. Поддерживаются ночные смены, перенос шаблонов и перенос назначенных смен между ячейками.

Клавиши 1–3 назначают шаблоны, Delete удаляет выделенные смены, Ctrl/⌘ + Z отменяет последнее изменение. Эти сочетания не перехватываются при вводе текста и времени.

«Сохранить» записывает изменения в PostgreSQL. «Опубликовать» сохраняет график и отмечает его опубликованным; рассылка сотрудникам в задание не входит. Последующее сохранение изменений возвращает график в черновик.

У каждого браузера своё демо-расписание, связанное с HttpOnly cookie на 30 дней. Общей учётной записи и авторизации нет. Смены сохраняются одной транзакцией; устаревшая версия при одновременном редактировании отклоняется. Очистка cookie создаёт новое расписание.

## Браузерные тесты

```sh
npx playwright install chromium
npm run test:e2e
```

База должна быть запущена и миграции применены. Playwright запускает dev-сервер автоматически или использует уже работающий. Проверяет свою смену после Escape, групповое назначение, сохранение, маршрутизацию с черновиком, перенос, поиск и мобильную форму.
